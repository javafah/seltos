# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this repository, please report it responsibly.

**Please do not** publish passwords, API keys, private information, or detailed instructions for exploiting a vulnerability in a public issue.

### How to Report

1. Visit the [javafah/seltos repository](https://github.com/javafah/seltos).
2. Open the repository's **Security** tab, if available.
3. If **Report a vulnerability** is available, use GitHub's private vulnerability reporting feature.
4. If private reporting is unavailable, contact the repository owner privately through a verified contact method listed on their GitHub profile.

Please include:
- A short description of the vulnerability.
- The affected file or feature.
- Steps to reproduce the issue safely.
- The potential impact.
- Any suggested fix, if known.

### What to Expect

I will review valid reports and work to address confirmed vulnerabilities. Please allow reasonable time for investigation and fixes before publicly disclosing the issue.

Thank you for helping keep this project safe!
